# Séances et entraînement (v1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter à Cahier une page « séance » (rappel, cours, condensé, quiz QCM), une progression par notion avec retour « à revoir », et un « Aujourd'hui » minimal, avec 5 séances réelles d'algorithmique.

**Architecture:** Site statique existant (HTML/JS vanilla, modules ES, routage par `#/`). Le contenu vit dans `contenu/` (fichiers fixes, listés par `contenu/index.json`). La progression est un module pur `js/progress.js` (localStorage, clé `cahier.progress.v1`). Les modules purs (progress, tirage de questions, vérificateur de contenu) sont testés avec `node --test` ; l'interface est vérifiée à la main sur un serveur local.

**Tech Stack:** JS vanilla (modules ES), `marked@12.0.2` (CDN jsDelivr), Node `node:test` pour les tests, `python -m http.server` pour servir.

**Spec:** `docs/superpowers/specs/2026-10-14-seances-v1-design.md`

## Global Constraints

- Pas de base de données, pas de framework, pas de build. Indentation 4 espaces, guillemets simples, textes d'interface en français, `escapeHtml` (de `./utils.js?v=6`) pour tout texte inséré dans `innerHTML`.
- Clé de progression exacte : `cahier.progress.v1`. Ne jamais lire ni écrire les clés existantes (`cahier_ics`, `cahier_agenda_collapsed`, données de `store.js`).
- Une notion est **acquise** après 2 réussites espacées d'au moins 1 jour ; elle repasse **à revoir** à +3 jours, puis +7 jours, puis +30 jours après sa dernière réussite comptée.
- Questions : QCM uniquement, `source` obligatoire, énoncé ≤ 400 caractères, chaque choix ≤ 120 caractères, 2 à 5 choix. `id` stable de forme `q-<séance>-<nnn>`.
- Annale **2023-2024 réservée** aux tests blancs : aucune `source` ne la cite. Les questions viennent de l'annale 2024-2025, des TD et des CM.
- `cours.md` et `condense.md` : Markdown simple (pas de wikilinks `[[…]]`, pas de callouts Obsidian `> [!…]`, pas de blocs mermaid). Images en chemin relatif `img/…`.
- Les PDF des profs ne doivent pas être commités : `contenu/**/support.pdf` est ajouté à `.gitignore` (Task 3).
- Commits : ajouter uniquement les fichiers listés dans la tâche (jamais `html ecampus/`, `tools/.chrome-profile/`). Commande type : `git add <fichiers> && git -c user.name="Abdul" -c user.email="pikatchu838@gmail.com" commit -m "<message>" -m "Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>"`.
- Écart avec la spec : chaque séance de `index.json` porte aussi un tableau `notions` (ids), pour que la liste des séances calcule les états sans charger chaque `quiz.json`.

## Review Focus

- `localStorage` absent, vide ou contenant du JSON corrompu → `progress.js` renvoie un état vide sans lever d'erreur (test Task 1).
- Deux réussites le même jour (ou à la même milliseconde) ne comptent pas comme « espacées » (test Task 1).
- Un `quiz.json` avec `bonne` hors bornes, un `id` en double ou une notion non déclarée dans l'index → le vérificateur échoue (tests Task 2).
- Une question mélangée garde la bonne réponse : après `preparerQuestion`, `choix[bonne]` est le même texte qu'avant (test Task 4).
- « Aujourd'hui » sans notion due et sans question d'annale → message clair, pas d'erreur (test Task 4 + vérification manuelle Task 8).
- Ouverture en `file://` ou serveur éteint → message « lance le serveur » au lieu d'une page blanche (Task 5, vérification Task 8).

```js
// Progression par notion : acquise après 2 réussites espacées d'un jour, puis rappels à +3 j, +7 j, +30 j.
const DAY = 24 * 60 * 60 * 1000;
export const INTERVALLES = [3 * DAY, 7 * DAY, 30 * DAY];
const KEY = 'cahier.progress.v1';

function memoryStorage() {
    const m = new Map();
    return { getItem: k => (m.has(k) ? m.get(k) : null), setItem: (k, v) => m.set(k, String(v)) };
}

function defaultStorage() {
    try { if (typeof localStorage !== 'undefined') return localStorage; } catch { /* accès refusé */ }
    return memoryStorage();
}

export function createProgress(storage = defaultStorage(), key = KEY) {
    function load() {
        try {
            const d = JSON.parse(storage.getItem(key));
            return d && typeof d === 'object' && d.notions && typeof d.notions === 'object' ? d : { notions: {} };
        } catch { return { notions: {} }; }
    }
    function save(d) {
        try { storage.setItem(key, JSON.stringify(d)); } catch { /* stockage plein ou refusé */ }
    }
    const cle = (seanceId, notion) => `${seanceId}/${notion}`;

    function etatDe(rec, now) {
        if (!rec) return 'pas-commencee';
        if (rec.acquiseLe) {
            if (rec.revoir) return 'a-revoir';
            return now >= rec.lastSuccess + INTERVALLES[rec.palier] ? 'a-revoir' : 'acquise';
        }
        return 'en-cours';
    }

    function getNotion(seanceId, notion, now = Date.now()) {
        const rec = load().notions[cle(seanceId, notion)];
        return { ...(rec || {}), etat: etatDe(rec, now) };
    }

    function recordAnswer(seanceId, question, ok, now = Date.now()) {
        const d = load();
        const id = cle(seanceId, question.notion);
        const rec = d.notions[id] || { n: 0, lastSuccess: null, last: now, acquiseLe: null, palier: 0, revoir: false };
        rec.last = now;
        if (ok) {
            if (rec.acquiseLe) {
                if (rec.revoir) { rec.revoir = false; rec.palier = 0; rec.lastSuccess = now; }
                else if (now >= rec.lastSuccess + INTERVALLES[rec.palier]) {
                    rec.palier = Math.min(rec.palier + 1, INTERVALLES.length - 1);
                    rec.lastSuccess = now;
                }
            } else if (rec.lastSuccess === null) { rec.n = 1; rec.lastSuccess = now; }
            else if (now - rec.lastSuccess >= DAY) { rec.n += 1; rec.lastSuccess = now; }
            if (!rec.acquiseLe && rec.n >= 2) { rec.acquiseLe = now; rec.palier = 0; }
        } else {
            rec.n = 0;
            rec.lastSuccess = null;
            if (rec.acquiseLe) rec.revoir = true;
        }
        d.notions[id] = rec;
        save(d);
    }

    function notionsDues(now = Date.now()) {
        const out = [];
        for (const [id, rec] of Object.entries(load().notions)) {
            const etat = etatDe(rec, now);
            if (etat !== 'a-revoir' && etat !== 'en-cours') continue;
            const i = id.indexOf('/');
            out.push({ seanceId: id.slice(0, i), notion: id.slice(i + 1), etat, last: rec.last });
        }
        const rang = { 'a-revoir': 0, 'en-cours': 1 };
        return out.sort((a, b) => rang[a.etat] - rang[b.etat] || a.last - b.last);
    }

    function etatSeance(seanceId, notionsIds, now = Date.now()) {
        const d = load();
        const etats = notionsIds.map(n => etatDe(d.notions[cle(seanceId, n)], now));
        if (etats.every(e => e === 'pas-commencee')) return 'pas-commencee';
        if (etats.every(e => e === 'acquise')) return 'acquise';
        if (etats.includes('a-revoir')) return 'a-revoir';
        return 'en-cours';
    }

    return { getNotion, recordAnswer, notionsDues, etatSeance };
}

export const progress = createProgress();
```

```js
// Vérifie contenu/ : index, fichiers, schéma des quiz, ids uniques, longueurs, annale réservée.
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const RESERVEES = [/2023-2024/];
const MAX_ENONCE = 400;
const MAX_CHOIX = 120;
const FICHIERS = ['cours.md', 'condense.md', 'quiz.json', 'support.pdf'];

export function verifierContenu(racine) {
    const erreurs = [];
    let index;
    try { index = JSON.parse(fs.readFileSync(path.join(racine, 'index.json'), 'utf8')); }
    catch (e) { return [`index.json illisible : ${e.message}`]; }

    const ids = new Set();
    for (const m of index.matieres || []) {
        for (const s of m.seances || []) {
            const ou = `${m.id}/${s.id}`;
            const dossier = path.join(racine, s.dossier || '');
            for (const f of FICHIERS) {
                if (!fs.existsSync(path.join(dossier, f))) erreurs.push(`${ou} : fichier manquant ${f}`);
            }
            for (const f of ['cours.md', 'condense.md']) {
                const p = path.join(dossier, f);
                if (!fs.existsSync(p)) continue;
                const txt = fs.readFileSync(p, 'utf8');
                if (/\[\[[^\]]+\]\]/.test(txt)) erreurs.push(`${ou}/${f} : wikilink [[…]] interdit`);
                if (/^>\s*\[!/m.test(txt)) erreurs.push(`${ou}/${f} : callout Obsidian interdit`);
                for (const mm of txt.matchAll(/\]\((img\/[^)\s]+)\)/g)) {
                    if (!fs.existsSync(path.join(dossier, mm[1]))) erreurs.push(`${ou}/${f} : image absente ${mm[1]}`);
                }
            }
            let quiz;
            try { quiz = JSON.parse(fs.readFileSync(path.join(dossier, 'quiz.json'), 'utf8')); }
            catch (e) { erreurs.push(`${ou} : quiz.json illisible (${e.message})`); continue; }
            if (quiz.seance !== s.id) erreurs.push(`${ou} : quiz.seance vaut "${quiz.seance}", attendu "${s.id}"`);
            const declarees = new Set(s.notions || []);
            const vues = new Set();
            for (const q of quiz.questions || []) {
                const qo = `${ou} ${q.id}`;
                if (!/^q-[a-z0-9-]+$/.test(q.id || '')) erreurs.push(`${qo} : id invalide`);
                if (ids.has(q.id)) erreurs.push(`${qo} : id en double`);
                ids.add(q.id);
                if (q.type !== 'qcm') erreurs.push(`${qo} : type "${q.type}" non géré en v1`);
                if (!declarees.has(q.notion)) erreurs.push(`${qo} : notion "${q.notion}" absente de l'index`);
                vues.add(q.notion);
                if (!q.enonce || q.enonce.length > MAX_ENONCE) erreurs.push(`${qo} : énoncé vide ou trop long`);
                if (!Array.isArray(q.choix) || q.choix.length < 2 || q.choix.length > 5) erreurs.push(`${qo} : il faut 2 à 5 choix`);
                else {
                    q.choix.forEach(c => { if (typeof c !== 'string' || !c || c.length > MAX_CHOIX) erreurs.push(`${qo} : choix vide ou trop long`); });
                    if (!Number.isInteger(q.bonne) || q.bonne < 0 || q.bonne >= q.choix.length) erreurs.push(`${qo} : bonne hors bornes`);
                }
                if (!q.explication) erreurs.push(`${qo} : explication manquante`);
                if (!q.source || !q.source.trim()) erreurs.push(`${qo} : source manquante`);
                else if (RESERVEES.some(r => r.test(q.source))) erreurs.push(`${qo} : annale réservée aux tests blancs`);
            }
            for (const n of declarees) if (!vues.has(n)) erreurs.push(`${ou} : notion "${n}" sans question`);
        }
    }
    return erreurs;
}
```

```js
// Fonctions pures pour construire une session de quiz.
export function melanger(tableau, rng = Math.random) {
    const a = [...tableau];
    for (let i = a.length - 1; i > 0; i--) {
        const j = Math.floor(rng() * (i + 1));
        [a[i], a[j]] = [a[j], a[i]];
    }
    return a;
}

export function preparerQuestion(q, rng = Math.random) {
    const ordre = melanger(q.choix.map((_, i) => i), rng);
    return { ...q, choix: ordre.map(i => q.choix[i]), bonne: ordre.indexOf(q.bonne) };
}

export function construireSession(questions, { max = 8, rng = Math.random } = {}) {
    return melanger(questions, rng).slice(0, max).map(q => preparerQuestion(q, rng));
}

function avecSeance(quizzes) {
    return Object.entries(quizzes).flatMap(([seanceId, quiz]) =>
        (quiz.questions || []).map(q => ({ ...q, seanceId })));
}

export function choisirDuJour(dues, quizzes, { max = 8, rng = Math.random } = {}) {
    const toutes = avecSeance(quizzes);
    const cles = new Set(dues.map(d => `${d.seanceId}/${d.notion}`));
    const revision = toutes.filter(q => cles.has(`${q.seanceId}/${q.notion}`));
    if (revision.length) return { mode: 'revision', questions: construireSession(revision, { max, rng }) };
    const annales = toutes.filter(q => /^annale/i.test(q.source || ''));
    if (annales.length) return { mode: 'annales', questions: construireSession(annales, { max, rng }) };
    return { mode: 'vide', questions: [] };
}
```

```js
// Accès aux fichiers de contenu/ (nécessite un serveur HTTP, pas file://).
const BASE = 'contenu/';
let indexPromise = null;

export function slug(s) {
    return s.normalize('NFD').replace(/[\u0300-\u036f]/g, '').toLowerCase()
        .replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '');
}

async function lire(chemin, type) {
    let res;
    try { res = await fetch(BASE + chemin); } catch { throw new Error('serveur'); }
    if (!res.ok) throw new Error(`Fichier introuvable : ${chemin}`);
    return type === 'json' ? res.json() : res.text();
}

export function chargerIndex() {
    indexPromise ??= lire('index.json', 'json').catch(e => { indexPromise = null; throw e; });
    return indexPromise;
}
export const chargerQuiz = (dossier) => lire(`${dossier}/quiz.json`, 'json');
export const chargerTexte = (chemin) => lire(chemin, 'text');

export async function trouverMatiere(nom) {
    const idx = await chargerIndex();
    return idx.matieres.find(m => m.id === slug(nom)) || null;
}

    return e.message === 'serveur'
        ? 'Impossible de lire le contenu. Lance le serveur depuis le dossier du site : python -m http.server 8000, puis ouvre http://localhost:8000.'
```

```js
// Quiz QCM : une question à la fois, correction immédiate, bilan en fin de session.
export function lancerQuiz(conteneur, questions, { onRetour } = {}) {
    let i = 0;
    let bonnes = 0;
    const ratees = [];
    const total = questions.length;

    if (total === 0) {
        conteneur.innerHTML = '<p class="quiz-vide">Aucune question disponible pour le moment.</p>';
        return;
    }

    function afficher() {
        const q = questions[i];
        conteneur.innerHTML = `
            <div class="quiz">
                <div class="quiz-top"><span>Question ${i + 1} sur ${total}</span>
                    <span class="quiz-bar"><i style="width:${(i / total) * 100}%"></i></span></div>
                <h3 class="quiz-enonce">${escapeHtml(q.enonce)}</h3>
                <div class="quiz-choix">${q.choix.map((c, k) => `<button class="quiz-choix-btn" data-k="${k}">${escapeHtml(c)}</button>`).join('')}</div>
                <div class="quiz-retour" hidden></div>
            </div>`;
        conteneur.querySelectorAll('.quiz-choix-btn').forEach(b => b.addEventListener('click', () => repondre(Number(b.dataset.k))));
    }

    function repondre(k) {
        const q = questions[i];
        const ok = k === q.bonne;
        progress.recordAnswer(q.seanceId, q, ok);
        if (ok) bonnes++; else ratees.push(q);
        conteneur.querySelectorAll('.quiz-choix-btn').forEach((b, idx) => {
            b.disabled = true;
            if (idx === q.bonne) b.classList.add('is-bonne');
            else if (idx === k) b.classList.add('is-fausse');
        });
        const retour = conteneur.querySelector('.quiz-retour');
        retour.hidden = false;
        retour.innerHTML = `
            <p class="quiz-verdict ${ok ? 'ok' : 'ko'}">${ok ? 'Exact.' : 'Pas tout à fait.'}</p>
            <p>${escapeHtml(q.explication)}</p>
            <p class="quiz-source">Source : ${escapeHtml(q.source)}</p>
            <button class="btn btn-primary" id="quiz-suivante">${i + 1 < total ? 'Question suivante' : 'Voir le bilan'}</button>`;
        retour.querySelector('#quiz-suivante').addEventListener('click', () => { i++; i < total ? afficher() : bilan(); });
    }

    function bilan() {
        const notions = [...new Set(ratees.map(q => q.notion))];
        conteneur.innerHTML = `
            <div class="quiz quiz-bilan">
                <h3 class="quiz-enonce">${bonnes} sur ${total}</h3>
                ${notions.length ? `<p>À retravailler : ${notions.map(escapeHtml).join(', ')}</p>` : '<p>Aucune erreur sur cette série.</p>'}
                <div class="quiz-actions">
                    ${ratees.length ? '<button class="btn btn-secondary" id="quiz-refaire">Refaire les ratées</button>' : ''}
                    <button class="btn btn-primary" id="quiz-fin">Terminer</button>
                </div>
            </div>`;
        conteneur.querySelector('#quiz-fin').addEventListener('click', () => onRetour && onRetour());
        const refaire = conteneur.querySelector('#quiz-refaire');
        if (refaire) refaire.addEventListener('click', () => lancerQuiz(conteneur, ratees.map(q => preparerQuestion(q)), { onRetour }));
    }

    afficher();
}
```

**Interfaces:**

- [ ] **Step 1: `js/today.js`**

```js
import { escapeHtml } from './utils.js?v=6';
import { chargerIndex, chargerQuiz, messageErreur } from './contenu.js';
import { progress } from './progress.js';
import { choisirDuJour } from './quiz-session.js';
import { lancerQuiz } from './quiz.js';

async function quizzesDe(seancesIds) {
    const idx = await chargerIndex();
    const quizzes = {};
    for (const m of idx.matieres) {
        for (const s of m.seances) {
            if (seancesIds && !seancesIds.has(s.id)) continue;
            quizzes[s.id] = await chargerQuiz(s.dossier);
        }
    }
    return quizzes;
}

// Carte d'accueil : combien de notions à revoir, bouton Commencer.
export async function renderTodayCard(element) {
    if (!element) return;
    try { await chargerIndex(); } catch { return; }
    const dues = progress.notionsDues();
    const texte = dues.length
        ? `${dues.length} notion${dues.length > 1 ? 's' : ''} à revoir aujourd'hui.`
        : 'Rien à rattraper : on peut attaquer une séance ou s\'entraîner sur les annales.';
    element.innerHTML = `
        <section class="today-card">
            <div><h2 class="today-titre">Aujourd'hui</h2><p>${escapeHtml(texte)}</p></div>
            <a class="btn btn-primary" href="#/aujourdhui">Commencer</a>
        </section>`;
}

// Page de session : 8 questions maximum, notions dues d'abord, sinon annales.
export async function renderAujourdhui() {
    const app = document.getElementById('app');
    app.innerHTML = '<div class="seance"><a class="back-link" href="#/">← Accueil</a><h1 class="seance-titre">Aujourd\'hui</h1><div id="today-quiz"><p>Préparation…</p></div></div>';
    const zone = app.querySelector('#today-quiz');
    try {
        const dues = progress.notionsDues();
        const quizzes = await quizzesDe(null);
        const { mode, questions } = choisirDuJour(dues, quizzes, { max: 8 });
        if (mode === 'vide') {
            zone.innerHTML = '<p class="quiz-vide">Rien à réviser pour l\'instant. Ouvre une séance et lance un premier quiz.</p>';
            return;
        }
        const intro = mode === 'revision' ? 'Notions à revoir.' : 'Rien à rattraper : entraînement sur des questions d\'annale.';
        zone.innerHTML = `<p class="today-intro">${intro}</p><div id="today-session"></div>`;
        lancerQuiz(zone.querySelector('#today-session'), questions, { onRetour: () => { window.location.hash = '#/'; } });
    } catch (e) {
        zone.innerHTML = `<p class="seance-erreur">${escapeHtml(messageErreur(e))}</p>`;
    }
}
```
