# TD 2 — Mots interrogatifs, en bref

| Information dans la réponse | Mot |
|---|---|
| personne, entreprise | Who |
| chose, action | What |
| choix dans un groupe | Which + nom |
| cause (because) | Why |
| lieu | Where |
| date | When |
| moyen | How |
| nombre | How many |
| quantité, prix | How much |
| fréquence | How often |
| durée | How long |

Mot interrogatif sujet : pas d'auxiliaire. Sinon : mot + do/does/did + sujet + base.

| Piège | Bon réflexe |
|---|---|
| Employer How much pour des pays | Ce qui se compte : How many |
| Confondre When et How long | Date : When. Durée : How long |
| Ajouter does après Which organization | Pas d'auxiliaire quand le mot est le sujet |
