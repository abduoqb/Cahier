# TD 3 — Question sur l'info soulignée, en bref

**4 étapes** : fonction, mot interrogatif, auxiliaire selon le temps, question sans la partie soulignée.

| Temps | Auxiliaire | Exemple |
|---|---|---|
| présent simple | do/does + base | How often do consumers replace… ? |
| prétérit | did + base | When did the campaign start ? |
| present perfect | has/have + participe | How long has Fairphone been producing… ? |
| modal | can + base | How can consumers reduce e-waste ? |
| passif | was/were + participe | Where was the television taken ? |

Sujet souligné : pas d'auxiliaire (Who is developing… ?).

| Piège | Bon réflexe |
|---|---|
| did started | did + base : did start |
| Recopier la partie soulignée | Elle disparaît |
| Pas d'inversion | Mot + auxiliaire + sujet |
