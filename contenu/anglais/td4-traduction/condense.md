# TD 4 — Traduction, en bref

| Français | Anglais |
|---|---|
| déchets électroniques | e-waste (indénombrable) |
| obsolescence programmée | planned obsolescence |
| appareil électroménager | household appliance |
| épuisement des ressources | depletion of resources |
| lutter contre | to fight, tackle, combat |
| mettre en place | to introduce, set up |

**Structures** : should + base ; before/without + -ing ; are gradually being introduced ; in recent years + present perfect.
